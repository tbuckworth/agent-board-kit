# The desktop's voice (bin/agent-speech, agentboard/speech.py): Kokoro and everything it needs, pinned, for a venv of
# its own; optional, and only for the Mac's ask box to speak (README, "The ask box on the Mac"). PyTorch is not here:
# install it into the venv first, as its CUDA libraries depend on the machine.
#   python3 -m venv ~/.local/share/agent-kit/speech-venv
#   ~/.local/share/agent-kit/speech-venv/bin/pip install torch
#       (the default Linux wheel has CUDA; for the CPU alone: --index-url https://download.pytorch.org/whl/cpu)
#   ~/.local/share/agent-kit/speech-venv/bin/pip install --no-deps -r board/requirements-speech.txt
#   agent-speech fetch          # Kokoro's model and voice, ~330 MB, once
# --no-deps keeps pip from fetching another torch; these pins (pip's resolution for kokoro 0.9.4 with misaki[en] 0.9.4,
# against torch 2.11.0) hold torch's own pure-Python needs too. A venv made with --system-site-packages reuses a torch
# installed already instead; add --ignore-installed to the last pip so each pin still lands in the venv.
# espeakng-loader carries espeak-ng's library and data, for words misaki's lexicon lacks: nothing is installed outside
# the venv.
